Prompt Bar Customizer

Documentation & Feature Guide

Welcome

Prompt Bar Customizer allows you to completely transform the text input areas of ChatGPT, Gemini, and DeepSeek. You can apply custom backgrounds, blurs, shapes, fonts, and even custom animated cursors.

Feature Breakdown

  • Glass & Liquid Glass: Apply standard CSS backdrop-filter blurs, or enable our experimental Liquid Glass setting for a dynamic, light-refracting SVG overlay (Chrome/Edge only).
  • DeepSeek & Gemini Specific Fixes: The extension automatically strips solid inner backgrounds so the blur effect shines through, and fixes overlapping buttons on DeepSeek.
  • Custom Cursors: Upload your own .png or .cur files, or import custom animated cursor libraries (.pbc.cul)!
  • Geometry: Warp, rotate, or resize the prompt bar. Make it a pill, a square, or a 3D perspective box.

Troubleshooting

If the styling stops working, the platform (ChatGPT/Gemini/DeepSeek) likely updated their website code (DOM). We have built robust fallbacks using :has() selectors and shadow-root scanning to handle this, but occasional updates may be required.

If you experience performance issues, try turning off "Liquid Glass" and "Smooth Animations".
